HIMACHAL EXPLORER - SEO PLAN (internal links + structured data)
================================================================
Built from your sitemap (65 pages) and your Search Console export (19 Jun - 18 Sep 2026).

FILES
  SEO-PLAN.xlsx                      Open in Google Sheets/Excel. Tabs: Start here, Schema by page type,
                                     Page map (all 65 pages), Link rules by intent, Query targets, Content gaps.
  breadcrumbs-ready-to-paste.txt     Ready BreadcrumbList markup for 62 pages (safe: built from the URLs).
  jsonld-templates/                  Templates for the other schema types. Anything in {{double braces}}
                                     must be replaced with facts that are visible on that page.

SUGGESTED ORDER
  1. Breadcrumbs on every page (the only visible Google feature you can add safely everywhere).
     Also show a matching visible breadcrumb on the page.
  2. Home page: template 01 (Organization + WebSite). Fill in logo, phone and social links first.
  3. Internal links: open the Page map, take the first 5 numbered links for each district page and
     each blog post, then the package pages. Use the anchor text shown.
  4. Query targets tab: for each district page, add the small answer blocks (altitude, distance,
     best time, where is...). These are searches where Google already shows you at position 50-90.
  5. Blog posts (4): template 05 (BlogPosting). Districts (12): template 03. Packages: template 04.
  6. Content gaps tab: decide which gaps to fill (no package for Bilaspur, Hamirpur, Una;
     no 7-day Spiti package for your 7-day Spiti article).

RULES
  - Only mark up what is visible on the page. No prices, no ratings or reviews you do not have.
  - Before publishing, search the page for "{{" : nothing with braces should go live.
  - Check each page in Google's Rich Results Test / Schema Markup Validator, and watch
    Search Console > Enhancements > Breadcrumbs after a few days.
  - Structured data does not raise rankings by itself; the internal links and page content do most of the work.
